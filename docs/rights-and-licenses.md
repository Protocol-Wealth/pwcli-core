# Rights and Licenses

Open-source software, open data, public metadata, and public-domain material are
not interchangeable. `pwcli-core` tracks rights explicitly.

## Recommended Fields

- SPDX expression when available.
- Rights statement URI when available.
- Access rights.
- Reuse allowed boolean.
- Human review required boolean.
- Notes for ambiguous terms.

## Rule

If rights are unclear, mark the record restricted for reuse until reviewed.
