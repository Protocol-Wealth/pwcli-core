# First Principles

- Conversational interfaces compile intent; deterministic systems own state.
- AI selects from registered primitives; it does not invent runtime UI or routes.
- Source metadata and AI interpretation stay separate.
- Standards are preferred before custom schemas.
- Mutating actions require explicit approval metadata.
