# Finance Workbench Example

Synthetic example for ledger-style review workflows. This example is generic and
asset-agnostic. It is not financial, investment, accounting, or tax advice.

## Flow

1. Parse a synthetic ledger fixture.
2. Classify review intent.
3. Hydrate a registered worksheet panel.
4. Require approval before any state-changing export or filing action.
5. Preserve source document references and review notes.
